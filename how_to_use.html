How to Use Snaplet

  1. Click the Start Photobooth button on the Home page, and if you are using a mobile device, we recommend enabling Desktop Site mode for a better user experience.
  2. Choose your preferred photo frame.
  3. Allow camera access when prompted.
  4. Press Ready to start. Your photos will be taken automatically 4 times, with a 3-second interval between each shot. Follow the countdown for each photo. Make sure you click Ready when the camera is already on so the photobooth process can run properly without errors. 📸
  5. Wait a moment while your photos are processed.
  6. Click the Download button to save your photo. After downloading, click Close to return to the Home page. If you don't want to download the photo, you can simply click Close to go back to Home.
